/**
 * utils/
 *
 * Place genuinely reusable helper functions here — functions that:
 *   - Are needed in multiple test files or page objects
 *   - Do not belong in a page object, fixture, or test-data file
 *
 * Before creating a new utility, ask:
 *   - Does this belong in a page object?   → pages/
 *   - Is this reusable test setup?         → fixtures/test-fixtures.js
 *   - Is this test data?                   → test-data/
 *
 * Only create a utility when none of the above applies.
 *
 * Example utility (add to a new file in this directory):
 *
 *   // utils/date-helpers.js
 *   function formatDate(date) {
 *     return date.toISOString().split('T')[0];
 *   }
 *   module.exports = { formatDate };
 */
